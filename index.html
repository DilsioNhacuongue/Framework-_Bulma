Porque usámos o Bulma

Escolhemos o Bulma para este trabalho por ser um framework CSS moderno que não depende de JavaScript para funcionar — as classes tratam do layout (colunas, cartões, navbar, botões) e nós concentramo-nos no conteúdo e na identidade visual de cada página. Isso tornou mais fácil manter as seis páginas do site consistentes entre si, sem repetir regras de CSS básicas em cada uma.

Em concreto, usámos os componentes columns, card, navbar, hero, tag e button, e ajustámos as cores e tipografia por cima através das variáveis CSS do Bulma 1.x, sem precisar de recompilar nada em Sass.
